NeuralVerse

Interactive VR & AI Learning Studio

Version 1.0.0 (Production)

Project Objective: A comprehensive desktop laboratory designed for the NPTEL/SWAYAM course Mobile Virtual Reality and Artificial Intelligence. Combines academic theory with real-time browser simulations, C# Unity script engineering, and Tabular Reinforcement Learning.

Technology Stack

  • Electron 28 (Desktop Framework, Multi-Window, IPC)
  • Node.js (Main Process, Native File Dialogs, Safe Storage)
  • ContextBridge & Preload (Zero Node integration in renderer)
  • HTML5 Canvas (Hardware-accelerated 3D & 2D Simulations)

Disclaimer: NeuralVerse is an independent educational companion developed for college coursework and viva examination. It is not affiliated with or endorsed by NPTEL/SWAYAM.
